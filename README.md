# Lead Tracker

Lead Tracker started as a learning project inspired by Scrimba. The goal is to make it easier to keep track of interesting opportunities without having to manually copy links into another application.

## Features

- **Save Lead** — Save a lead or URL entered into the input field.
- **Save Tab** — Save the URL of the current browser tab for later reference.
- **Delete All** — Clear all saved leads when you no longer need them.

## Getting Started

### 1. Download the Release
1. Head over to the Releases Page of the repo or `https://github.com/firstskylord/Lead-Tracker/releases`
2. Select the latest version and download the zip file, named in the format of `Lead.Tracker.v100.zip`, into desired directory.

### 2. Load the extension in your browser
1. Open `chrome://extensions/`
2. Enable Developer mode
3. Click Load unpacked
4. Select the directory containing the extension's `manifest.json` file **(Important)**
5. Pin the extension to your toolbar and start using it.
